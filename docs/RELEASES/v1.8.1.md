# Release notes — Quantum Llama Terminal v1.8.1

## Overview

This release focuses on system stability, a more professional user interface, and two
classes of critical fixes: multi-platform session handling (MT5 / crypto) and the generation
of technical documentation.

## Bug fixes

- **AlgoLab loading error** — fixed `NameError: name 'sys' is not defined` in the dashboard
  generator, so the technical help and documentation load correctly both in development and
  in the packaged executable.
- **Platform detection** — the broker detection engine (`detectPlatformType`) now prioritizes
  symbol patterns (MNQ, ES, NQ). This resolves the endless loading state in **detached
  (popout) charts** when MT5 symbols are opened from a global crypto session.
- **MT5 / crypto session persistence** — quick-save now uses the active symbol context, so
  MT5 settings are stored in their own session instead of being overwritten or lost in the
  crypto session.
- **Workspace selector** — the header selector shows the active workspace name instead of a
  generic label, and `WORKSPACE 1` is the default name.
- **Dropdowns in dark mode** — `select` and `option` elements keep a dark, readable theme
  across browsers instead of falling back to a white background.

## UI/UX and branding

- **Branding suppression** — CSS rules hide third-party logos, watermarks and links
  (TradingView / Lightweight Charts) throughout the platform, including the VIX correlation
  panel.
- **Selector design** — soft borders, custom accent arrow icons and `JetBrains Mono`
  typography for a financial-terminal aesthetic.
- **VIX panel** — smoother rendering of the VIX correlation panel, free of external visual
  elements.

## Stability and performance

- **Session synchronization** — session tokens and data follow a chart detached into its own
  window, so the popout keeps the configuration of the main panel.
- **Symbol cache cleanup** — legacy symbol formats are purged automatically at startup to
  avoid conflicts with the local database.
